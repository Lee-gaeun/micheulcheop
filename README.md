# micheulcheop
🍽️ 미슐첩 — 내 입맛이 기준이 되는 미식 수첩. 다녀온 맛집을 사진, 글, 별점으로 기록하고 나만의 맛집 가이드를 만들어가는 앱.

## 실행

Node.js 22 이상에서 `npm run dev` 실행 후 http://localhost:5173 에 접속합니다. 별도 패키지 설치는 필요하지 않습니다.

## 현재 구현

- 모바일·데스크톱 반응형 앱 화면과 홈 화면 추가용 웹 앱 매니페스트
- 여러 개인·공유 수첩 생성, 이름·색상·이모지·소개 변경
- 사진 업로드 및 크기 최적화, 짧은 후기, 0.5 단위 5점 만점 평가
- 기록 수정·삭제, 방문일, 수첩별 검색과 별점·최신순 정렬
- 수첩별 피드·지도 전환, 카카오맵 장소 링크와 Kakao Maps JavaScript SDK 연결
- 댓글 작성·수정·삭제, 닉네임 변경, JSON 백업 내려받기
- 브라우저 localStorage 저장

## 개발 범위와 제한

현재는 로컬 체험 버전입니다. 계정 인증, 실제 멤버 초대, 온라인 공동 작성·권한 제어 및 기기 간 동기화는 구현하지 않았습니다. 공유 수첩의 초대 화면에 이를 안내합니다. 앱스토어 배포용 네이티브 앱은 아닙니다.

기록 작성 시 카카오맵에서 식당·카페를 검색하고 선택하면 장소명·주소·분류·좌표·장소 ID를 자동 저장합니다. 사진은 휴대폰의 사진 선택창으로 고를 수 있습니다. 카카오 JavaScript 키가 없으면 카카오맵 링크와 장소 목록을 제공합니다. 키가 설정되면 앱 안 지도에 수첩의 장소 마커를 표시하고 마커 클릭 시 기록 상세를 엽니다. 사진·지도·웹 폰트에는 인터넷 연결이 필요합니다. 초기 맛집·후기·댓글과 좌표는 UI 확인용 예시이며 실제 식당 정보의 정확성을 보장하지 않습니다. 브라우저 데이터 삭제 시 로컬 기록도 삭제됩니다. 사진을 많이 올릴 경우 브라우저 저장 한도에 도달할 수 있습니다.

`npm run check`로 문법 검사를, `npm test`로 수첩 생성·4.5점 기록·댓글·지도·수첩 간 분리·저장 흐름을 검사합니다. 자동 검사는 모의 문서 환경에서 실행되며 실제 브라우저의 시각적 검증을 대신하지 않습니다.

## 카카오맵 설정

`config.js`의 `kakaoJavaScriptKey`에 카카오 개발자 앱의 공개 JavaScript 키를 넣고 SDK 도메인에 `http://localhost:5174`를 등록합니다. 다른 포트나 운영 주소에서는 해당 주소도 등록해야 합니다. 지도 API 사용 권한도 활성화되어 있어야 합니다. Admin 키나 REST API 키를 사용하지 마세요. 키가 없어도 카카오맵 외부 링크는 동작합니다.

공식 가이드: https://apis.map.kakao.com/web/guide/

즐겨찾기: 피드와 기록 상세의 북마크로 저장·해제하고 하단 즐겨찾기 메뉴에서 모든 수첩의 저장한 글을 모아봅니다. 검색과 정렬이 지원되며 이 브라우저에 유지됩니다. 사진 선택창의 구체적인 모양과 갤러리/파일 앱 제공 방식은 휴대폰과 브라우저에 따릅니다. 현재는 사진 한 장을 선택합니다.

## 기록 작성 흐름

추가 버튼 또는 지도 탭의 기록하기에서 카카오 지도를 열고 장소를 검색합니다. 지도 마커나 검색 결과를 고른 뒤 여기에 기록하기를 누르면 작성 화면으로 이어집니다. 장소를 바꿀 때도 사진과 글은 유지됩니다. 별의 왼쪽/오른쪽을 누르면 0.5점 단위로 선택할 수 있고 키보드 화살표로도 조절할 수 있습니다. 후기는 5,000자까지 작성하며 피드에서는 네 줄로 요약되고 상세에서 전체 내용을 읽습니다. 사진·별점·후기를 바꾸면 아래 피드 미리보기에 반영됩니다. 사진은 피드에서 잘려 보일 수 있고 상세에서는 원본 비율로 표시합니다. 글꼴은 Noto Sans KR과 시스템 산세리프를 사용합니다. 화이트·차콜에 버건디를 포인트로 쓰고, 수첩의 사용자 지정 색상은 표지의 책등에 반영됩니다.

장소 검색 자동 추천: 입력을 약 0.3초 멈추면 식당·카페 검색 결과를 합쳐 최대 5개를 검색창 아래에 표시합니다. 한글 조합 중에는 요청을 보류하고, 새 입력이 들어오면 이전 결과를 무시합니다. 검색 버튼과 Enter로 즉시 검색할 수도 있습니다.

현재 위치: 지도 탭과 새 기록용 지도는 브라우저 위치 권한을 허용하면 내 위치로 이동합니다. 권한 거부·시간 초과·미지원 상황에는 기존 지도 중심을 유지합니다. 사용자가 검색하거나 지도를 조작한 뒤 도착하는 위치 응답은 자동으로 화면을 되돌리지 않습니다. 기존 장소를 선택한 경우에는 그 장소가 우선이며, 지도 안 현재 위치 버튼으로 돌아갈 수 있습니다. 좌표는 최대 1분간 메모리에만 캐시하며 수첩 데이터나 백업에 저장하지 않습니다. 실기기에서는 HTTPS 또는 localhost 환경이 필요합니다.

## 프로필 사진과 카카오 로그인

마이에서 사진을 고르면 중앙을 정사각형으로 맞춘 384px 미리보기가 표시되고, 프로필 저장 후 상단과 내 글 작성자 사진에 반영됩니다. 기본 이미지로 버튼도 저장 후 반영됩니다. 사진은 이 브라우저에만 저장됩니다.

카카오 로그인은 서버 OAuth 인가 코드 흐름과 HttpOnly 세션 쿠키를 사용합니다. 토큰과 Client Secret은 브라우저로 전달하지 않습니다. 실제 로그인 준비:

1. 카카오 개발자 콘솔에서 해당 앱의 카카오 로그인을 ON으로 설정합니다.
2. Redirect URI에 `http://localhost:5174/auth/kakao/callback`을 등록합니다.
3. 동의항목에서 프로필 정보(닉네임·프로필 사진)를 필요한 범위에서 설정합니다. 미동의 정보가 없어도 기본 프로필로 로그인합니다.
4. 로컬 `.env.local`에 `KAKAO_REST_API_KEY`와 `KAKAO_CLIENT_SECRET`을 넣습니다. 이 파일과 비밀 값은 공유하거나 커밋하지 마세요. 운영에서는 환경변수로 주입하고 PUBLIC_ORIGIN을 실제 HTTPS 주소로 설정합니다.
5. 서버를 재시작하고 마이 > 카카오 로그인을 누릅니다.

계정 인증만 연결하며 수첩의 서버 저장·다른 기기 동기화·계정별 데이터베이스는 아직 없습니다. 기록은 기존처럼 현재 브라우저에 유지됩니다. 로그인 세션은 서버 메모리에 보관하여 서버 재시작 또는 토큰 수명 만료 후 재로그인이 필요합니다. 이 버전은 사용량이 제한된 로컬 개발용이며 운영에는 영속 세션 저장소와 계정별 기록 저장소가 필요합니다.

인증 관련 응답은 캐시하지 않으며 서버는 공개 파일 목록만 제공하여 .env.local과 서버 소스가 URL로 노출되지 않도록 제한합니다.
