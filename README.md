# 🍽️ 미슐첩

내 입맛이 기준이 되는 미식 수첩. 혼자 또는 친구와 함께 맛집을 사진·글·별점으로 기록하는 모바일 웹 앱입니다.

## 실행

Node.js 22 이상이 필요합니다. 별도 패키지 설치 없이 실행할 수 있습니다.

1. `.env.example`을 `.env.local`로 복사합니다.
2. 카카오 로그인용 REST API 키와 Client Secret을 입력합니다.
3. `npm run dev` 실행 후 `http://localhost:5174`에 접속합니다. `.env.local` 없이 실행하면 기본 포트는 5173입니다.

`.env.local`과 `.data/`는 Git에서 제외되며 서버의 공개 파일 목록에도 포함되지 않습니다. 비밀 값은 공유하거나 커밋하지 마세요. `config.js`의 카카오 JavaScript 키는 지도에 필요한 공개 브라우저 키입니다.

## 기능

- 개인 수첩, 여러 공유 수첩, 이름·이모지·표지 책등 색상 꾸미기
- 카카오맵 현재 위치, 검색창 자동완성 최대 5개, 선택한 장소 핀 하나만 표시
- 지도에서 장소 선택 후 기록 작성, 식당명·주소·분류·좌표 자동 입력
- 사진 최대 10장 선택·좌우 편집·순서 변경·사진별 글, 별 모양 표시와 0.1점 단위 슬라이더 평가
- 5,000자 후기, 실시간 피드 미리보기, 상세에서 사진 원본 비율 표시
- 피드·지도 탭, 검색·정렬, 댓글, 즐겨찾기
- 프로필 사진 편집, 닉네임 변경, 카카오 로그인·로그아웃, 30일 로그인 유지
- JSON 백업 내려받기

## 친구 초대와 공동 작성

카카오 로그인 후 새 공유 수첩을 만들거나, 기존 수첩의 멤버 초대에서 온라인 공유 수첩으로 전환합니다.

- 관리자가 7일 유효한 초대 링크를 만들고 복사할 수 있습니다. 앱이 다른 사람에게 메시지를 자동 전송하지 않습니다.
- 초대받은 사용자는 수첩 소개를 확인하고 카카오 로그인 후 명시적으로 참여합니다.
- 참여자는 같은 수첩의 기록을 읽고 각자의 사진·후기·별점·댓글을 남깁니다.
- 작성자만 자신의 글과 댓글을 수정·삭제합니다. 닉네임이 같아도 계정 ID로 권한을 검사합니다.
- 관리자는 이름·꾸미기·멤버와 초대 링크를 관리합니다. 일반 멤버는 수첩에서 나갈 수 있습니다.
- 초대 링크 만료·취소와 멤버 내보내기가 즉시 서버 권한에 반영됩니다.
- 같은 글을 동시에 수정하면 버전 충돌을 알리고 오래된 내용으로 덮어쓰지 않습니다.
- 화면을 보고 있고 작성 창이 닫혀 있으면 약 8초마다 변경 내용을 확인합니다. 변경이 없으면 화면을 다시 그리지 않습니다.
- 즐겨찾기는 계정별로 보관합니다.

기존 기기 수첩을 전환할 때는 예시 기록을 제외한 본인 기록을 서버로 옮깁니다. 원래 수첩과 댓글은 브라우저의 `localArchives` 백업에 보관하며 JSON 백업에 포함됩니다. 예전 댓글은 작성자 계정을 검증할 수 없어 새 공유 수첩으로 옮기지 않습니다. 한 번에 최대 100개 기록을 전환할 수 있습니다.

개인 수첩과 아직 전환하지 않은 기기 수첩은 기존처럼 브라우저에 보관됩니다. 공유 데이터는 로컬 저장소에 복제하지 않으며, 로그아웃하면 화면에서 제거됩니다.

## 공용 주소와 배포

무료 배포 구성은 [DEPLOY.md](DEPLOY.md)를 참고하세요. Render Free + Supabase Free를 사용하며 `render.yaml`과 `supabase/schema.sql`이 포함되어 있습니다. Supabase를 연결하면 사진은 비공개 Storage로 분리하고 공유 기록은 클라우드 DB에 저장합니다.

`localhost` 초대 링크는 친구의 휴대폰에서 접속할 수 없습니다. 여러 기기에서 함께 쓰려면 모든 사용자가 접속 가능한 HTTPS 서버로 배포해야 합니다.

배포 시 `PUBLIC_ORIGIN`을 실제 HTTPS 주소로 설정하고 카카오 개발자 콘솔의 JavaScript SDK 도메인과 로그인 Redirect URI도 같은 주소로 변경하세요. 카카오 개발 모드 앱은 테스트 가능한 계정 범위도 콘솔에서 확인해야 합니다.

Supabase를 연결하지 않은 로컬 개발에서는 공유 기록·회원 표시 정보·초대 해시·즐겨찾기를 `.data/collaboration.json`에 원자적으로 저장합니다. 파일 교체와 쓰기 직렬화로 중간 저장 및 동시 쓰기 손실을 방지합니다. **단일 서버 프로세스용**이므로 배포 환경에 영속 저장 볼륨을 연결하고 `.data/`를 백업해야 합니다. 여러 서버 인스턴스를 운영하려면 데이터베이스로 교체해야 합니다.

로그인 세션 ID의 SHA-256 해시와 만료일을 서버 저장소에 보관합니다. 클라이언트에는 HttpOnly/SameSite 쿠키만 전달하며 HTTPS에서는 Secure를 적용합니다. 로그인은 30일 유지되고 서버 재시작 후에도 복구됩니다. 로그아웃은 저장소의 세션을 폐기합니다. 카카오 액세스 토큰은 영구 저장하지 않습니다. 기존 로그인은 업데이트 후 한 번 다시 로그인해야 합니다.

## 카카오 설정

지도:

- JavaScript 키의 SDK 도메인에 `http://localhost:5174` 등록
- 카카오맵 사용 설정 ON
- 공개 JavaScript 키는 `config.js`에 설정

로그인:

- 카카오 로그인 활성화
- 사용한 REST API 키의 Redirect URI에 `http://localhost:5174/auth/kakao/callback` 등록
- 필요에 따라 프로필 닉네임·사진 동의항목 설정. 미제공 시 기본 프로필 사용
- `.env.local`의 `KAKAO_REST_API_KEY`, `KAKAO_CLIENT_SECRET` 설정 후 서버 재시작

공식 문서: https://apis.map.kakao.com/web/guide/ · https://developers.kakao.com/docs/ko/kakaologin/rest-api

사진 편집은 정사각형을 기본으로 핀치 확대(1~4배), 터치 드래그 위치 조절과 원본·따뜻하게·산뜻하게·선명하게·부드럽게·흑백 필터를 지원합니다. 적용 결과는 미리보기에 반영되고 기록을 저장할 때 업로드됩니다. 편집 중인 새 사진의 원본은 브라우저 메모리에만 유지되며, 저장 후 다시 편집할 때는 저장된 사진을 기준으로 합니다. 사진 위에는 글자를 최대 8개 추가하고 드래그로 배치할 수 있습니다. 글자 색상·크기를 고를 수 있고, 적용 시 사진에 함께 포함됩니다. 사진 순서는 작은 사진 목록에서 끌어 변경하며, 편집기와 미리보기는 각자 보고 있던 사진을 유지합니다. 방문일은 날짜 카드와 오늘 버튼으로 선택합니다. 새 기록은 사진별 글만 입력합니다. 사진을 넘기면 피드·미리보기·상세의 사진 아래 후기 영역도 해당 사진의 글로 바뀝니다. 기존 전체 후기는 숨김 데이터로 보존하고 기존 기록에서 계속 표시합니다.

## 수첩과 댓글

수첩 상단에서 기본 수첩을 지정하면 해당 계정의 이 브라우저에서 재접속 시 먼저 열립니다. 개인 수첩은 기기에서 삭제하며 공유 수첩은 관리자만 삭제할 수 있습니다. 삭제 시 기록·댓글·초대·즐겨찾기도 정리됩니다. 댓글에 한 단계 답글을 남길 수 있으며 부모 댓글 삭제 시 답글도 함께 삭제됩니다.

## 현재 위치와 사진

위치 권한을 허용하면 새 지도는 내 위치로 시작합니다. 거부·시간 초과 시 기존 지도 중심을 유지하고, 이미 장소를 선택하거나 지도를 움직인 뒤에는 위치 응답이 늦게 도착해도 화면을 되돌리지 않습니다. 현재 위치는 메모리에 잠시 캐시하며 기록이나 서버에 자동 저장하지 않습니다. 모바일 위치 API는 HTTPS 또는 localhost가 필요합니다.

사진은 최대 10장을 선택하고 각 사진에 2,000자까지 글을 남길 수 있으며 브라우저가 지원하는 이미지 형식이 필요합니다. 사진 선택창의 구성은 휴대폰과 브라우저에 따릅니다. 지도·외부 예시 사진·웹 폰트는 인터넷 연결이 필요합니다. 초기 식당·사진·후기·좌표는 예시 데이터입니다.

## 검사

- `npm run check`: 소스 문법 검사
- `npm test`: 로컬 저장·별점·프로필·검색·위치·로그인·공동 작성 검사

공동 작성 검사는 임시 폴더에 실제 파일을 저장하며 두 사용자 초대·참여·작성·댓글, 권한 분리, 위조 작성자 무시, 동시 저장, 재시작 복구, 수정 충돌, 계정별 즐겨찾기, 링크 만료·취소, 멤버 제거를 검증합니다. 실제 친구 계정으로 공용 배포 환경에 접속하는 검사는 별도입니다.
